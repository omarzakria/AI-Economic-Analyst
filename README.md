# AI Economic Analyst 🤖📊

إزيكوم عاملين إيه 👋

حبيت أشارك معاكم فكرة مشروع بتاعي.

كتير مننا بيكون عنده حلم إنه يبدأ **Brand** أو **Business** خاص بيه، لكن ممكن ما يكونش عنده وقت أو خبرة كافية يعمل **Feasibility Study** ويحسب رأس المال، التكاليف، والعائد المتوقع.

ومن هنا جاتلي فكرة المشروع:

## 💡 فكرة المشروع
عملت **System** باستخدام **Python** و **OOP**، ومربوط بـ **Google Gemini API**، مع واجهة تفاعلية باستخدام **Streamlit**، بحيث يساعد المستخدم في عمل تحليل وتوقع لفكرة المشروع.

### 📥 المستخدم بيدخل:
* **اسم المشروع وفكرته**
* **الـ Budget المتاحة**

### 📤 والـ System بيقدم:
* **تحليل وتوقع اقتصادي باستخدام الـ AI**
* **تخزين دراسات الجدوى:** عملت **Database** باستخدام **SQLite3** لحفظ دراسات الجدوى السابقة، بحيث تقدر ترجع لها في أي وقت.

---

> الفكرة بالنسبة لي كانت إني أستخدم **AI + Data + Economics** في حاجة عملية تساعد أي شخص بيفكر يبدأ مشروعه. 🚀

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Python** 🐍
* **Object-Oriented Programming (OOP)** 🏗️
* **Google Gemini API** 🧠
* **Streamlit** 🎈
* **SQLite3** 💾
